# 112-overblik

Værktøj til at følge 112-sager fra hændelse over politiet til retten.

Hjemmesiden består af én fil (`index.html`) og kører i browseren. Sagerne gemmes i din egen Excel-database. Data bliver aldrig uploadet. Siden læser og skriver kun den fil, du selv vælger.

**Brug:** Åbn siden i Edge eller Chrome, og vælg din Excel-database med "Åbn Excel-fil". Brug "Gem til Excel" (eller Ctrl+S) for at gemme.
